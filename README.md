# React Admin Dashboard - API Training Demo

## 📝 Project Description
This repository is a practical training demo of an Admin Dashboard built using **React** and **Vite**. It is generated from a custom localized template based on `shadcn-admin`, meaning it inherits full **multilingual (English/Arabic)** and **RTL (Right-to-Left)** layout support out of the box.

The main focus of this project is to practice and demonstrate production-ready frontend architecture by integrating RESTful APIs using **Axios** and managing complex client-side navigation via **React Router**.

## ✨ Key Features
* **Multilingual & RTL Ready:** Seamless switching between Arabic (RTL) and English layouts.
* **API Integration:** Robust HTTP request handling, data fetching, and error states using **Axios**.
* **Dynamic Routing:** Clean client-side navigation and protected routes managed by **React Router DOM**.
* **Shadcn/ui Components:** Clean, accessible, and beautifully styled UI components using Tailwind CSS.

## 🛠️ Tech Stack
* **Frontend Core:** React.js (Vite)
* **Styling & Components:** Tailwind CSS, shadcn/ui
* **Routing:** React Router DOM
* **Networking:** Axios

## 🚀 Installation & Setup

1. **Clone the repository:**
```bash
   git clone https://https://github.com/Mohammed-Invs7/react-admin-demo-api.git
```
Install dependencies:
```bash
   npm install
```
Run the development server:
```bash
   npm run dev
```
